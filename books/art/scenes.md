# Scene prompts (AI illustration → AI animation)

For each page:
1. **Image:** start with the style anchor from `characters.md` and attach the character sheet(s), then add the image prompt below.
2. **Animate:** upload the chosen still to an image-to-video tool (Kling, Runway, Veo, Seedance) as the *first frame*,
   attach the character reference too, and use the motion prompt. Make 5–10 s clips. Ask for a **seamless loop** where the tool supports it.
3. **Drop in:** save as `web/media/pNN.png` (still) or `web/media/pNN.mp4` (clip), e.g. `p07.mp4`.
   The web book and the video use it automatically instead of the drawing.

Keep the bottom ~20% of every picture calm (grass, floor, table): the text box sits there.

## Video-tool tips
- Always use the still as the first frame: text-only video makes the characters drift.
- Short clips (5 s) keep faces stable; generate 2–3 takes and keep the best.
- If a face morphs, cut the clip shorter: in the book, the clip loops.
- Turn off generated sound/music in the tool. Narration is added by `tools/record-video.mjs`.
